## 📌 Overview

Smart Event Planner is a full-stack web application that helps users efficiently plan and manage events.
It provides tools for task tracking, guest management, budget estimation, and data visualization.

The platform also integrates an **AI-based budget estimation feature** to assist users in making smarter planning decisions.

---

## ✨ Features

### 🗂️ Event Management

* Create and manage events
* Add event details (title, date, budget, description)

### ✅ Task Management

* Add and track tasks
* Mark tasks as completed
* Real-time progress tracking

### 👥 Guest Management

* Add guests to events
* Manage guest lists

### 📊 Analytics Dashboard

* Visual insights using charts
* Event completion statistics
* Task progress tracking

### 📅 Calendar View

* View events in a calendar format
* Better scheduling and planning

### 🤖 AI Budget Estimation

* Generates budget suggestions based on event type
* Uses Gemini API with fallback logic

### 🌙 UI/UX Features

* Dark mode support
* Smooth animations (Framer Motion)
* Fully responsive design

## 🚀 Getting Started (Local Setup)

### 1. Clone Repository

```bash
git clone https://github.com/your-username/event-planner.git
cd event-planner
```

---

### 2. Backend Setup

```bash
cd server
npm install
npm run dev
```

Create `.env` file:

```
MONGO_URI=your_mongodb_url
GEMINI_API_KEY=your_api_key
PORT=5000
```

---

### 3. Frontend Setup

```bash
cd client
npm install
npm run dev
```
